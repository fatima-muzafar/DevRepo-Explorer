# AI Assistance

## Overview

This project was developed using AI-assisted tools to improve productivity, support problem-solving, and streamline the development process. AI was used as a development assistant rather than a replacement for software engineering decisions.

All AI-generated suggestions were carefully reviewed, tested, refined, and validated before being incorporated into the final application.

---

## AI Tools Used

| Tool | Purpose |
| :--- | :--- |
| GitHub Copilot | Code completion, implementation assistance, and boilerplate generation within Visual Studio Code. |
| ChatGPT | Project planning, software design discussions, prompt engineering, architecture guidance, debugging assistance, documentation, and development best practices. |

---

## How AI Was Used

AI assisted throughout the project lifecycle, including:

- Planning the project architecture.
- Breaking the project into manageable development phases.
- Generating implementation prompts for GitHub Copilot.
- Discussing React and TypeScript best practices.
- Designing reusable component structures.
- Providing guidance for Firebase Authentication and Cloud Firestore integration.
- Assisting with GitHub REST API integration.
- Identifying potential bugs and debugging strategies.
- Suggesting accessibility and responsive design improvements.
- Improving loading states, error handling, and user experience.
- Assisting with testing strategies and code quality reviews.
- Creating and refining project documentation, including the README.

---

## Development Workflow

The project followed a structured AI-assisted workflow:

1. Plan each development phase with ChatGPT.
2. Generate focused implementation prompts.
3. Implement features using GitHub Copilot.
4. Review all generated code manually.
5. Test functionality after each phase.
6. Refine and improve the implementation where necessary.
7. Repeat the process until project completion.

This iterative workflow helped maintain code quality while reducing repetitive development tasks.

---

## Human Review

Every AI-generated suggestion was evaluated before being accepted.

This included:

- Reviewing implementation logic.
- Verifying TypeScript type safety.
- Testing application functionality.
- Fixing bugs and edge cases.
- Improving code readability and maintainability.
- Ensuring consistency across the project.
- Validating accessibility and responsive behaviour.

No AI-generated code was merged into the project without manual review and verification.

---

## Transparency Statement

AI tools were used to support development, documentation, and problem-solving throughout this project. Final implementation decisions, code reviews, testing, debugging, and refinements were completed manually to ensure correctness, maintainability, and adherence to project requirements.
